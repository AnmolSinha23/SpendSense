DBMS Project Note: How This Report Works

This reports page is powered by the relational database view view_monthly_category_summary. Instead of doing math in Python, MySQL runs an INNER JOIN across the transactions and categories tables, performs a GROUP BY on user, year, month, and category, and calculates summary metrics using SUM(), COUNT(), and AVG() directly in the database engine.
